# 🚀 PrajnaVerse — Personal Portfolio Website

Welcome to the official repository of **PrajnaVerse**, the personal portfolio website of **Raushan Raj**, Computer Engineering student at **NIT Kurukshetra (2022–2026)**.

---

## 📌 Project Overview

**PrajnaVerse** is a sleek, modern, dark-ember themed personal portfolio website designed to showcase engineering projects, technical skill sets, experience, and contact functionality with full Google Sheets backend integration.

### ✨ Key Features:
- 🎨 **Ember Charcoal Design Theme:** Custom CSS with refined dark mode palette, gold accents, and responsive layout.
- 🖼️ **Profile Portrait Frame:** Displays custom profile artwork (`raushanraj.jpeg`).
- 📄 **Resume Download Integration:** Direct download link for `raushanraj.docx`.
- 📊 **Google Sheets Backend Integration:** 
  - **Form Submissions (`POST`):** Interactive contact form sends data directly into a Google Sheet using Google Apps Script.
  - **Dynamic Data Reader (`GET`):** Reads dynamic content/projects from Google Sheets in real-time.
- ⚡ **SVG Favicon:** Embedded lightweight dark/gold "PV" monogram tab icon.
- 🌐 **GitHub Pages Ready:** Zero-build static hosting ready to deploy out-of-the-box.
